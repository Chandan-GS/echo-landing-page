# Echo — Landing Page

Marketing landing page and privacy policy for **Echo**, a privacy-first personal briefing app
that captures your notifications, SMS and calendar and reads you a calm spoken briefing each
morning — processed on-device by default.

## Files

- `index.html` — the landing page (hero, how-it-works, feature sections, real app screenshots
  in phone frames, engine choice, voices, privacy trust section, footer).
- `privacy.html` — a standalone, Google-Play-ready privacy policy.
- `screenshots/` — product shots (`shot-home.png`, `shot-ask.png`, `shot-voice.png`) rendered
  from the real app UI mockups.
- `echo-mascot.svg` — the Echo mascot ("the sound sprite"), inlined into the pages and used for
  the favicon.
- `favicon-256.png`, `favicon-32.png` — favicons rendered from the mascot.
- `og-image.png` — 1200×630 social/Open Graph preview.
- `_reference/` — the source app-UI mockups and the single-phone render copies used to generate
  the screenshots (not part of the deployed site).

## Brand

- Type: **Old Standard TT** (serif headings) + **Nunito** (body), via Google Fonts.
- Colors: paper `#F4F2EE`, forest green `#49884F`, charcoal `#141810`.
